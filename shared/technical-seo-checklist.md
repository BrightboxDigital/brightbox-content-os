## Keep Rank Math. Do not put title or meta description in the article HTML.

**Decided July 19, 2026.** This was considered and rejected for a concrete technical reason.

The SEO title and meta description live in the page `<head>`. The article HTML goes in the post
**body**. A Custom HTML block cannot write to the `<head>`, so:

- A `<title>` placed in the body is invalid and browsers ignore it for the real page title.
- A `<meta name="description">` placed in the body is ignored by Google.

Verified on the live site July 19, 2026: the redesign article's `<head>` title and meta description
are generated by Rank Math. That is exactly the job Rank Math does, along with the canonical tag and
the Article schema. Removing it would mean losing all of that, not just the two fields.

**So the title and meta description are set in Rank Math, by hand, per article.** The `wp-draft`
script cannot write them because Rank Math does not expose `rank_math_title` or
`rank_math_description` to the REST API (confirmed: zero rank_math fields are REST-writable on this
install). That is a two-field manual step per article, taken from the article package.

If that step ever becomes worth automating, the path is a small mu-plugin that registers those two
Rank Math meta keys with `show_in_rest`, after which `wp-draft` could set them. Not worth it for two
fields at two articles a month. Revisit only if volume grows.
